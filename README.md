# Make the AI Judge Laugh: Cat Reviews Its Human

One deadpan one-star review of a human, written by the house cat. Run the builder:

```sh
python main.py
```

It verifies `entry.txt` against the gate and copies it to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, printing a JSON receipt.
